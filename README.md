# Aprendiendo TypeScript 2

Proyecto personal de aprendizaje y ejercicios prácticos sobre **TypeScript**.

**Autor:** Sasha Zubiria

## Metodología de Estudio
Este repositorio está estructurado para seguir los módulos del curso *"TypeScript: Tu completa guía y manual de mano"*. 
Para mantener el entorno limpio y organizado:
1. Cada tema tiene su propio archivo dentro de la carpeta `src/bases/`.
2. Para visualizar el resultado de un tema específico en la consola, se debe descomentar el `import` correspondiente dentro de `src/main.ts` y comentar los demás.

## Progreso

### Módulo 1: Tipos de datos en TypeScript
En esta etapa inicial, he repasado los conceptos fundamentales:
* **Tipos Primitivos:** `string`, `number`, `boolean`, `null`, `undefined`, `symbol`.
* **Tipos Compuestos:** Objetos, Funciones, Arreglos y Tuplas.
* **Conceptos clave:** Inferencia de tipos, uso restringido de `any`, manejo de `void/never`, uso de `Enums` y encadenamiento opcional.
